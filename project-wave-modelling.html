Adaptive PINNs for elastic waves

Can a neural network learn how elastic waves travel through layered ground, without a mesh? We compared three kinds of PINNs against finite-difference simulations.

INSIGHTS
01 Architecture matters more than input features Fourier features alone barely helped on Marmousi2 (18.25% against 20.71%). Changing the network to PirateNet cut the error to 1.67%.
02 Standard PINNs drift over time By the last time step, standard PINNs reached 35 to 45% error while PirateNet stayed at 3%.
03 Sharp layer boundaries are hard The material models were smoothed or low-pass filtered. Earlier thesis work also found smoothing velocity jumps helped training converge.
04 What this does not show yet One run per setup, 2D constant-density media, simulated data only. There are no field measurements on concrete yet.
